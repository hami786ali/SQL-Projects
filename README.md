# SQL-Projects
SQL projects completed during the Leep Talents Data Skills Bootcamp, showcasing database queries, data retrieval and analysis.
# About This Repository

This repository showcases my SQL exercises and projects completed during the Leep Talents Data Skills Bootcamp.

The work focuses on developing practical skills in querying databases, retrieving information and analysing structured data.

# Skills and Techniques

Writing SQL queries

Retrieving data using SELECT

Filtering records using WHERE

Combining tables using JOINs

Grouping and summarising data using GROUP BY and aggregate functions

# Projects and Exercises

SQL Query Exercises

A collection of SQL exercises completed during the bootcamp to practise retrieving, filtering and analysing data from relational databases.

Tools: SQL and database management tools used during the course.

Learning Outcomes

These exercises are helping me develop my understanding of relational databases, SQL syntax and techniques for extracting useful information from structured datasets.
